# InterviewPractice

## LP Delivery Coach

Single-file web tool for Amazon SDE 2 LP interview **delivery** feedback via an LLM.

### Run

1. Open `index.html` in **Chrome** (Web Speech API for live recording).
2. Paste your API key in the page or set `API_KEY` at the top of the script in `index.html`.
3. Record or paste your answer, then click **Analyze delivery**.

No build step or dependencies.
